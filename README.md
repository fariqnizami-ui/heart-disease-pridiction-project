# Heart Disease Prediction App 🫀

This project uses a **Random Forest Classifier** to predict the presence of heart disease based on clinical parameters. The model achieved an accuracy of **86.89%** during training.

## 🛠️ Features
* Predicts heart disease status based on user input.
* Built with `scikit-learn` and `Streamlit`.
* Deployed via Streamlit Cloud.

## 📂 Project Structure
* `app.py`: The Streamlit web application.
* `heart_disease_model.pkl`: The trained Random Forest model.
* `heart-disease.ipynb`: The original Jupyter Notebook used for EDA and training.
* `requirements.txt`: List of required Python libraries.
